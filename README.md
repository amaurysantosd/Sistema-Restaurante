# Sistema Restaurante

ERP Web para gerenciamento de restaurantes.

## Objetivo

Criar um sistema moderno, modular e escalável para gerenciamento completo de restaurantes.

## Tecnologias

- Docker
- PostgreSQL
- Node.js
- NestJS
- Next.js
- TypeScript

## Estrutura

```
Sistema-Restaurante
├── backend
├── frontend
├── database
├── docker
├── docs
├── diagrams
├── prototypes
└── backups
```
